# Contributing

Anything goes. Send a line; the maintainer picks.

- Reply wherever you saw unbind, or open an issue, or PR `words.md` and run `python3 tools/build_pairs.py`.
- Short lands harder. The original is one word: "Coffee".
- Five kinds: absurd, hard (something worth doing instead), brand, literal, formula (whole sentence, uses `{brand}`).
- New brand: real greeting, where you saw it, cropped screenshot with the date in the filename, one template per language. Copy the Claude section in `words.md`.
- Data for your own script: `https://unbind.eytoss.com/data/pairs.json`. Stable fields; `version` changes when the words do.
- Brand names as plain text, no logos. Screenshots cropped to the greeting.
